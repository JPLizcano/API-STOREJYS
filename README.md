*** NOTAS GIT *** 

*** Para conectarse a un repositorio ***

git init.
git remote add origin (link)
git branch -M (rama)

*** Para hacer pull: ***

git add .
git commit -m "mensaje"

*** En caso de que tenga la rama con cambios hacer paso 1 y 2 sino hacer solo 3 y 4 ***

git pull origin (rama)

*** Para hacer push: ***

git add .
git commit -m "mensaje"
git push -u origin (rama)

*** En caso de resabios, la rama esté vacía, se sabe lo que se hace ***

git push -u origin (rama) --force
